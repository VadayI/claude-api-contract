# Handoff

Within an authorized documentation task, inspect actual branch/HEAD/status and
the current plan. Update the existing `docs/HANDOFF.md` with the concrete task,
known revision/tree, changed paths, actual commands/results, unresolved blockers
and next step. Preserve unrelated notes. Append a concise session record to the
existing WORKLOG; do not copy private chat, env values or raw logs into Git.
Do not invent the SHA of the future commit containing the handoff. A stale SHA
requires relevant diff reconciliation, not deletion of historical notes. Report
exact written paths and the evidence used. Coordinators dispatch this writing to
a worker; reviewers return findings only.
